REI OS · Beta 0.1.0

Make a little room
on your desktop.

The real desktop app, with your own messages and saved plans. These are early beta builds; the browser demo above stays separate and uses sample data.

Windows

x64 · Standalone .exe

Download for Windows ↓

Open the app directly. WebView2 is required. No Node.js or Rust setup.

macOS

Apple Silicon & Intel · Universal .dmg

Download for Mac ↓

Open the disk image and drag REI OS into Applications.

Windows is unsigned. macOS uses an ad-hoc signature and is not notarized by Apple; your system may block the first opening. Release notes and checksums ↗

For AI, choose local Ollama with an installed model, or configure your own supported API key in Settings. Accounts and models are not included in the download.

An honest preview

Still growing. Already worth exploring.

REI is a desktop app in development. This browser demo demonstrates its planning workflow using sample data and prewritten summaries; it does not run the desktop backend or a live AI model.

HIZ is the current university email connector. Teams, cloud sync, and a full conversational assistant with searchable memory are not available in this preview. Beta downloads are available above; platform acceptance testing is still in progress.
