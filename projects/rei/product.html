REI is a desktop app in development. This browser demo demonstrates its planning workflow using sample data and prewritten summaries; it does not run the desktop backend or a live AI model.

HIZ is the current university email connector. Teams, cloud sync, and a full conversational assistant with searchable memory are not available in this preview. A public installer is not ready yet.
