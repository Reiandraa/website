Windows

x64 · Standalone .exe

Download for Windows ↓

Open the app directly. WebView2 is required. No Node.js or Rust setup.

macOS

Apple Silicon · M-series Macs

Download for Mac ↓

Unzip and move REI OS to Applications. Apple Silicon only; Intel Macs are not supported by this build.

Windows is unsigned; the Mac beta is ad-hoc signed and not Apple-notarized. Your system may block the first opening. Release notes and checksums ↗

For AI, choose local Ollama with an installed model, or configure your own supported API key in Settings. Accounts and models are not included in the download.

An honest preview

Still growing. Already worth exploring.

REI is a desktop app in development. This browser demo demonstrates its planning workflow using sample data and prewritten summaries; it does not run the desktop backend or a live AI model.

Email supports HIZ, secure provider discovery, and Google/Microsoft browser sign-in. Google sign-in is currently limited to invited beta testers, and university account policies may require approval. Teams, cloud sync, and a full conversational assistant with searchable memory are not available in this preview. Windows and Apple Silicon Mac opening and email sign-in have been tested by the creator; wider device testing is ongoing.
